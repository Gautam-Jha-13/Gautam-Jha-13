### 🏛️ AuctionHub
**Microservices auction platform**

<img src="https://skillicons.dev/icons?i=spring,java,gradle,postgres,docker" height="32"/>

- Auth, auction, bid, notification & API-gateway services — each an independent Spring Boot 3.2 / Java 21 module
- Spring Cloud Gateway as the single entry point, Eureka for service discovery
- Each service backed by its own Postgres container via Docker Compose
- Next up: OpenFeign for inter-service calls

</div>

### 🎟️ ReserveX
**Distributed ticket booking backend** — BookMyShow-inspired

<img src="https://skillicons.dev/icons?i=spring,java,postgres,redis" height="32"/>

- Auth module with JWT + Spring Security, Swagger-documented
- Redis-based seat locking (`SETNX` + TTL) to solve race conditions on booking
- Booking & payment modules with a mocked payment gateway
- Clean `/api/v1/` REST design with a standard `ApiResponse<T>` envelope
